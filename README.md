# Site-Lite

Site-Lite is the internal website layer for OuRi's visual website builder.

## Vision

A lightweight project format that allows users to create websites visually, edit parameters, animations and components, then export clean HTML/CSS/JavaScript.

## Architecture

```
Site-Lite
├── core/           Engine runtime
├── editor/         Visual editor
├── components/     Reusable blocks
├── assets/         Images, icons, fonts
├── animation/      Timeline and effects
├── exporter/       HTML/CSS/JS exporter
└── docs/           Documentation
```

## Features roadmap

- Live preview
- Component system
- Parameter-based design
- Animation timeline
- Asset manager
- ZIP project import/export
- HTML/CSS/JS export
- Future beta HTML import
